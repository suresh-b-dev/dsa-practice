# DSA Practice

My Data Structures and Algorithms practice in JavaScript, organized by topic and difficulty. Each problem has its own folder for the brute-force approach, plan, final solution, tests, and reflection.

## Repository structure

```text
dsa-practice/
├── README.md
└── arrays-strings/
    ├── README.md
    ├── easy/
    │   └── problem-name/
    ├── medium/
    │   └── problem-name/
    └── hard/
        └── problem-name/
```

I’ll add more topic folders as I study them, such as `linked-lists`, `stacks-queues`, `trees-graphs`, `backtracking`, and `dynamic-programming`.

## Files for each problem

```text
problem-name/
├── README.md
├── brute-force.md
├── plan.md
├── solution.js
└── solution.test.js
```

For a small problem, I can keep the notes together in its `README.md` instead of creating extra files.

## Problem workflow

1. Read the problem and note its constraints.
2. Try to solve it independently before looking for help.
3. Record the straightforward brute-force approach.
4. Write a plan for a more efficient approach before coding.
5. Implement the final solution in JavaScript and test edge cases.
6. If I get stuck, ask for a short hint and continue solving on my own.
7. Record what I learned and revisit problems that need more practice.
