Add each new problem as its own folder. Use lowercase kebab-case names and keep its notes, solution, and tests together.

Example:

```text
easy/
└── problem-name/
    ├── README.md
    ├── brute-force.md
    ├── plan.md
    ├── solution.js
    └── solution.test.js
```
